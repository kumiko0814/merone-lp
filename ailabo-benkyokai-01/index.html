冷蔵庫にあるもので、今夜の晩ごはんを3つ提案して。 ・冷蔵庫にあるもの：〇〇、〇〇、〇〇 ・家族：大人2人・子ども2人（辛いのが苦手）など ・条件：30分以内で作れる／火を使いすぎない など 作り方も、かんたんな手順で教えて。

6分 WHY DAILY

なぜ「毎日」話しかけるのが
大事なの？

AIは、話した分だけ
あなた専用のプロに育つから。

さっきの差を思い出してください。まっさらなAIと、育てたAI。ちがいは頭の良さではなく、「あなたのことをどれだけ知っているか」だけです。

  • 今日の出来事・悩み・愚痴・やりたいこと——なんでも話しかけていい
  • 「調べもの」「文章づくり」「壁打ち」——1日1回でもいいから続ける
  • 話すたびに、あなたの言葉づかい・状況・好みが伝わり、答えが"あなた仕様"に近づく
合言葉：「うまく頼めない」と悩む前に、まずたくさん話す。上手な頼み方は、話しているうちに勝手にうまくなります☺️
10分 TWO KINDS

「チャット」と「Claude Code」
のちがい

チャットに慣れてきたら、次のステップがClaude Codeです。同じClaudeでも、できることが変わります。

💬 Claude チャット⌨️ Claude Code
たとえると電話ごしの賢い相談相手パソコンの前に座る助手
できること話す・考える・文章・アイデアそれに加えてパソコンを操作・ツールを動かす
メルカリのリンク❌ 読めない（数字やスクショを渡す）⭕ 開いて分析できる
使う人まずは全員ここでOK慣れてきた人・本格的にやりたい人
必要なものスマホ・無料でOKパソコン＋設定（少し上級）
今日の私（くみこ）の画面がメルカリを読めたのは、「Claude Code＝パソコンを操作できる版」を使っていたからです。みんなのチャット版は"話すのが得意な版"。まずはそこを使いこなして、いつかCodeに挑戦、でOKです。
「Claudeなら何でもできる、ではなく"版によって違う"」を必ず言う。生徒がアプリでリンク貼って失敗するのを防ぐ。焦らせず「いつか」でいい、と安心させる。
8分 HANDOVER

AIの記憶は、
場所ごとに"別々"です

ここ、みんながつまずくところ。チャットで話したことは、Claude Codeには自動で伝わりません。逆も同じ。ChatGPTとClaudeも、記憶はつながっていません。

同じ「Claude」でも、チャットの記憶とCodeの記憶は別の箱。ChatGPTとClaudeも別の箱。それぞれの場所に、それぞれの記憶が育ちます。

だから「引き継ぎ書」を作らせる

引っ越し・お引き継ぎのときは、片方のAIに「引き継ぎ書を作って」と頼んで、それをもう片方に渡します。これで記憶を持ち運べます。

これまで私と話してきたことをふまえて、 別のAIに引き継ぐための「引き継ぎ書」を作って。 ・私の仕事／家族／大事にしていること ・今取り組んでいること ・私の話し方の好み を、そのままコピーして渡せる形でまとめて。

→ これを、引っ越し先のAI（Claude Code や 新しいチャット）に貼れば、ゼロからやり直さずに済みます。

5分 🎁 今日のプレゼント

ChatGPTから Claudeへ
「お引っ越し」する魔法の言葉

普段ChatGPTを使っている人が多いですよね。ChatGPTには、あなたのことがもう溜まっています。それをClaudeに引っ越しさせましょう。まずChatGPTにこれを打ってください。

あなた（ChatGPT）がこれまで私について知ったことを、 別のAI（Claude）に引き継ぐための「私の取扱説明書」を作ってください。 次の項目を、そのままコピーして渡せる形でまとめて： ① 私の仕事・立場 ② 家族構成・暮らし ③ 私が大事にしている価値観 ④ いま取り組んでいること・目標 ⑤ 私の話し方や、してほしい返し方の好み ⑥ 覚えておいてほしい注意点 やさしい言葉で、箇条書きでお願いします。

# スマセル6月プロモーション 戦略提案パッケージ（パブリック公開サンプル）

これは株式会社Merone（メローネ）プロモーション事業部が、スマセル媒体向けに作成した社内提案書のパブリック公開サンプルです。

## 重要な前提

- 本書は **Merone社内の意思決定用に作成された実プロジェクト提案書** をベースとしています。
- パブリック公開のため、以下をすべて匿名化しています：
  - 個人実名（成約者・離脱者・データ提供者・関係者）→ アルファベット記号（Aさん／Bさん／データ提供者Z等）
  - 取引先実名 → 「スマセル運営担当者」「クライアント側担当者」等の役割名
  - 社内スタッフ実名 → 「Merone代表」「CTO」「社内スタッフ」等の役割名
  - 医療情報・センシティブな個人事情 → 該当文の完全削除または「個人的事情」と要約
  - 取引・売上の具体数字 → 「数十万円台」「数百万円規模」等の定性表現
  - LINE発言の直接引用 → 要約に置き換え
- **戦略の骨子・KPIロジック・配信文設計・ツール仕様等、意思決定に必要な情報は保持** しています。
